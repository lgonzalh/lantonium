SEVETCO

Plataforma de gestión para equipos y proveedores, con experiencias web y móvil.

Reseña

SEVETCO combina un panel web de administración y proveedores con una aplicación móvil para apoyar las tareas de gestión desde distintos dispositivos.

Funcionalidades

  • Panel web para administración y proveedores.
  • Acceso desde dispositivos móviles.
  • Autenticación y gestión de información integrada con Firebase.
