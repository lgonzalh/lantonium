Cóndor

PRODUCTO · .NET / IA · 2026 · En desarrollo

Herramienta local-first de ingeniería de software asistida por IA que conserva el contexto, la arquitectura y las decisiones de cada proyecto.

Reseña

Condor es una plataforma local-first de ingeniería de software asistida por inteligencia artificial que prioriza el conocimiento del proyecto antes que la generación de código. Preserva el contexto, mantiene la coherencia arquitectónica y convierte cada decisión en conocimiento permanente mediante documentación viva, trazabilidad y desarrollo guiado por arquitectura. En Condor la conversación es temporal: la documentación es la fuente oficial de verdad.

Funcionalidades

  • Documentación viva como fuente oficial de verdad: el contexto no se pierde entre sesiones.
  • Desarrollo guiado por arquitectura: comprender, planificar, diseñar, implementar, verificar y documentar.
  • Trazabilidad de decisiones técnicas en documentos permanentes.
  • Modelos de IA locales (LLM) sin dependencia de servicios externos.
  • Continuidad entre sesiones, herramientas y modelos sin depender de conversaciones anteriores.

Tecnologías

.NET · C# · Ollama para modelos locales · Clean Architecture (CLI / Core / Infrastructure) · Markdown

OFUserControlApp

SOFTWARE · IDENTIDADES · 2026 · Desarrollado

Audita identidades mediante archivos Excel, contrasta usuarios con Active Directory y sincroniza los resultados.

Reseña

OFUserControlApp es una solución de ingeniería de software desarrollada en ASP.NET Core 10.0 diseñada para la gestión crítica de identidades mediante el procesamiento automatizado de archivos Excel de alta volumetría. La aplicación implementa Clean Architecture para garantizar una separación estricta de intereses, utilizando PostgreSQL sobre Supabase como motor de persistencia cloud-native. El sistema optimiza el flujo de validación de usuarios contra el Directorio Activo, permitiendo detectar discrepancias de acceso y estados de actividad de forma ágil, asegurando el cumplimiento de las políticas de seguridad y gobernanza de datos en entornos empresariales complejos. (2025)

Funcionalidades

  • Validación Cruzada Automatizada: Ejecución de algoritmos de coincidencia entre listados externos y el Directorio Activo mediante el cruce de datos en capas de base de datos optimizadas.
  • Arquitectura N-Layer Escalable: Implementación estructurada (Domain, Application, Infrastructure) que permite la extensibilidad del sistema y el desacoplamiento de la lógica de negocio.
  • Monitoreo Transaccional en Tiempo Real: Interfaz dinámica potenciada por SignalR que proporciona retroalimentación instantánea sobre el progreso de la carga y el procesamiento de registros.
  • Procesamiento de Datos: Motor de integración de hojas de cálculo de alto rendimiento para la extracción, validación y exportación de reportes técnicos detallados.

YT Downloader - Clipper

HERRAMIENTA · MULTIMEDIA · 2026 · Desarrollado

Herramienta de escritorio para descargar videos y extraer segmentos específicos de audio y video.

Reseña

YT Downloader - Clipper es una aplicación de escritorio desarrollada en Python que proporciona una interfaz gráfica intuitiva y directa para la gestión de descargas multimedia. El sistema integra el potente motor de procesamiento de yt-dlp y FFMPEG, permitiendo no solo la descarga de videos completos y audios en alta definición, sino la capacidad avanzada de extraer segmentos de tiempo específicos ("clipping"). Esto reduce significativamente los tiempos de transferencia, el uso de ancho de banda y el almacenamiento, descargando únicamente el fragmento de interés. Su diseño legacy standalone y portabilidad lo convierten en una utilidad altamente eficiente y robusta para preparar el material audiovisual desde esa fuente de manera local.

Funcionalidades

  • Extracción Precisa de Segmentos: Controles integrados para establecer tiempos de inicio y finalización exactos, permitiendo descargar clips específicos directamente desde el origen sin necesidad de post-procesamiento.
  • Selección Multi-Formato y Calidad: Permite configurar la descarga en modo Video + Audio, Solo Video o Solo Audio, con selector dinámico de resoluciones hasta 1080p y superiores según disponibilidad.
  • Monitoreo de Telemetría de Red: Barra de progreso en tiempo real que expone métricas críticas como porcentaje completado, velocidad de transferencia (MiB/s), tiempo estimado de finalización (ETA) y tamaño del archivo.
  • Interfaz Gráfica Funcional (GUI): Panel de control minimalista que incluye integración directa con el portapapeles del sistema para agilizar el flujo de entrada de URLs y definición de directorios de destino.

Tecnologías

Python 3 · Tkinter · yt-dlp · FFmpeg · Pillow · SQLite
